## 2. connection(namespace) semantics
- 레거시 `connect()`/`_connect_postgres()`: 동작·시그니처 불변. baseline search_path=`public, core`(pool configure/reset). <!-- 현행은 platform·pg_temp 포함 — §10.1/§10.3 -->
- 신규 `connection(ns)`(어댑터): `_validate_namespace(ns)`(allowlist `^(core|platform|skill_[a-z0-9_]+)$`) → 트랜잭션 열고 `SET LOCAL search_path TO <ns>, platform, core, pg_catalog`(identifier 목록, **신규 경로엔 public fallback 없음 → 미이관 테이블 fail-fast**) → yield → txn 종료 시 자동 복원. autocommit 상태 단독 `SET LOCAL` 은 no-op 이므로 반드시 txn 안에서.
- 풀 누수 봉쇄: configure(신규 물리커넥션마다 baseline SET) + reset(check-in 마다 baseline 재정규화). advisory **xact** lock 은 DB-global·스키마무관·커밋 자동해제 → finding_upsert/goal_record_turn 경로 불변.

## 3. register_schema(namespace, baseline_ddl, *, migrations=(), idless_tables=(), concurrent_steps=())
- **등록=순수 메모리**(플러그인 import 시 DB/pool 무접근): allowlist 검증 → `_REGISTERED_SCHEMAS[ns]=SchemaSpec`(checksum, 동일=no-op·상이=conflict) → `_PG_IDLESS_TABLES.update(idless_tables)`(DDL 前 정합).
- **적용=lazy·별도 경계**(`apply_registered_schemas()` 또는 첫 connection(ns)): per-ns `pg_advisory_lock(hashtext('schema:'||ns))` → `CREATE SCHEMA IF NOT EXISTS <ns>` → `SET LOCAL search_path=<ns>,pg_catalog`(스킬 unqualified CREATE 가 core/platform 로 새지 않게) → baseline_ddl → 미기록 migrations(version 순) → concurrent_steps(txn 밖) → **GRANT USAGE+SELECT + ALTER DEFAULT PRIVILEGES** to read-only 롤(env `SA_PG_READONLY_ROLE`, best-effort) → unlock. 멱등=프로세스 `_SCHEMA_READY_NS` + DB `core.schema_version(namespace, phase, version, checksum, applied_at)`.
- read-only 안전: `SHOW transaction_read_only` 확인 후 DDL/GRANT 전면 skip(validate-only). 등록만이면 실패 안 함.

## 4. core FULL-MOVE 부트스트랩 (state.py `_connect_postgres` 첫연결)
전체를 DB `pg_advisory_lock(hashtext('secu_agent:core-bootstrap'))` 로 감쌈(멀티워커 직렬화):
1. `CREATE SCHEMA IF NOT EXISTS core` (+ `platform` 빈스키마 for P2).
2. `SET search_path TO core, pg_catalog`(부트스트랩 스코프).
3. relocate: for t in CORE_TABLES(16): `to_regclass('public.'||t) NOT NULL AND to_regclass('core.'||t) IS NULL` → `SET LOCAL lock_timeout='2s'` 하 `ALTER TABLE public.<t> SET SCHEMA core`(best-effort; 실패=public 잔류, 그래도 baseline `public,core` 로 resolve → 무중단). ALTER SET SCHEMA 는 owned identity sequence 동반 이동(RESTART IDENTITY 정합).
4. 기존 de-domain RENAME ALTER(now core.<t>) → `executescript(_SCHEMA)`(누락분 core 에 CREATE, IF NOT EXISTS) → 추가 ALTER(chat_goal/session) → `_ensure_schema_version` → pg_trgm + core.finding_index trgm index → **GRANT USAGE/SELECT on core**.
5. `SET search_path TO public, core, pg_catalog`(baseline 복원) → `_PG_SCHEMA_READY=True` → yield. <!-- 현행 baseline=§10.2(platform·pg_temp 포함), 부트스트랩은 platform provision 도 수행 -->
fresh _test DB: public 사본 부재 → relocate no-op → core 로 clean CREATE.

## 9. codex 적대리뷰 처리 (INC4)
codex 개방형 리뷰가 다수 지적. **운영 중지 중(단일 migrator·롤링배포/구워커/라이브 split-brain 무관)** 과
**orchestrator P1 dormant(스킬 미사용)** 맥락으로 triage.

### 수정 완료 (P1 반영)
- **split-brain fail-closed**(high): relocate 를 4-상태로 — public만→이동, core만→no-op, 둘다→hard fail,
  이동 실패는 삼키지 않고 raise(빈 core.<t> 생성으로 인한 분기 차단).
- **read-only validate-only**(high): read-only 롤이면 16 core 테이블 존재를 검증, 누락 시 fail-closed(조용한 '성공' 후 첫쿼리 실패 방지).
- **advisory lock 유계 대기**(high): `SET lock_timeout` 을 lock 획득 前으로(부트스트랩+orchestrator).
- **orchestrator 원자성/checksum**(high): migration DDL+version 기록을 한 트랜잭션으로, `_applied_checksum` 조회오류
  미삼킴(fail-closed), phase별 checksum drift 검출(baseline=baseline_ddl 단독 해시), core.schema_version 매테스트 초기화.
- **namespace fullmatch+길이제한**(high): `$`→`fullmatch`+≤63(위장 식별자 차단). idless 식별자 검증.
- **core/platform register_schema 거부**(med): 코어 소유. idless funnel 을 registry 공개와 같은 lock 경계로(레이스 차단).
- **search_path pg_temp 명시 마지막**(high-보안): 임시 테이블 shadowing 차단. `_reset_registry` 가 readiness 도 초기화.
- **doctor split-brain 감지**(med): public 잔존 코어 테이블 검출 시 fail. **_PgConn.raw** 공개(private `_conn` 결합 제거).

### 연기 (운영 runbook / P2 / 신뢰 DB 전제 — 설계상 의도)
- **롤링배포/구워커 호환**(운영): P1 은 운영중지 창에서 1회 이관 전제. 라이브 무중단 배포가 필요하면 public 호환 view
  또는 qualified SQL 단계배포 — **P2 컷오버 runbook**(§7.3).
- **connection(ns)+finding cross-txn unit-of-work / idle-in-txn 타임아웃**(P2 API): 스킬이 connection(ns) 를 실제 쓰는 P2 에서
  UoW API 또는 finding_upsert(conn=...) 내부경로 + statement/idle 타임아웃 규약.
- **정규화 SQL / _PG_INSERT_RE schema-prefix 업그레이드**(P2 선행): hot-path 를 core.finding_lifecycle 로 qualify 하려면 선행 패치(§7.5).
- **idless (namespace,table) 키**(P2): 현 P1 은 전역 bare-name(코어/스킬 테이블명 disjoint 전제). schema-prefix 업그레이드와 함께.
- **스키마 owner/ACL 검증·PUBLIC CREATE 회수 / GRANT strict·metric / concurrent_steps indisvalid**(운영 하드닝): 신뢰 사내 DB 전제로
  P1 best-effort. 게이트웨이 read-only GRANT 는 P1 이 core 에 부여(SA_PG_READONLY_ROLE), P2 가 skill_*/platform 에.
- **conftest CASCADE 범위 / 독립 sequence RESTART**: 전용 _test DB 강제(conftest)로 커버, 독립 sequence 스킬 도입 시 P2 규약.

무결 판정(codex): autocommit `raw.transaction()`+`SET LOCAL` 스코핑, `format('%I.%I')` truncate SQLi 안전,
표준 owned-sequence RESTART IDENTITY, finding 위임 1:1 시그니처.

### 10.2 R2 하드닝 — 커밋 2b8080c (codex a2a 2라운드 적대검증 "R2 완결 승인")
- **R2-1 구 shape 수렴**: platform DDL 을 테이블 / 마이그레이션(6 `ADD COLUMN IF NOT EXISTS`) / 인덱스 3분리 —

  raise → psycopg_pool 이 그 물리 커넥션을 폐기(오염 전파 차단). `apply_schema` finally 도 lock_timeout 복원.
- **R2-4 read-only validate 강화**: relation+public 잔존 외에 platform 재귀속 잔재 + **마이그레이션 6컬럼 전부**

- **R2-5**: 코어 `pyproject` 에 `psycopg>=3.2` + `psycopg-pool>=3.2` 선언(풀은 코어 소유).
- **codex 적대검증 후속 수정**:
  - **함수 shadowing 차단**: reset 은 '이전 borrower 의 오염 가능 search_path' 에서 돌기 때문에 built-in **15곳**
    (`current_setting`·`to_regclass`·`hashtext`·`pg_advisory_*`·`set_config`)을 `pg_catalog.` 로 한정
    (reset/configure/bootstrap/apply_schema + 런타임 goal/finding upsert advisory). 의미상 no-op, shadowing 방어.
  - **platform provision 원자화**: `_provision_platform_schema` 를 `raw.transaction()` 한 블록으로(relocate+DDL
    부분 provision 방지) + `SET LOCAL search_path`(txn 스코프 자동복원) + GRANT 는 txn 밖(롤 부재 GRANT 실패가
    provision 전체를 롤백하지 않게).
- **보류(런북/raw 접근 계약)**: `IF NOT EXISTS` 는 컬럼 존재만 수렴(타입/NULL/DEFAULT/인덱스 shape 미검증 —

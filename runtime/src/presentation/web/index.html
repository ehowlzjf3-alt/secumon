상시 임무 새 사건의 관측 상태와 제어

상시 임무를 등록할 때 받은 제어 업무 ID로 조회하세요. 아래 제어는 새 사건 관측에 적용됩니다. 이미 접수된 개별 업무의 일시정지·취소는 해당 업무 화면에서 할 수 있습니다.

관측 종료 후에는 같은 규칙을 재개할 수 없습니다. 조회·제어는 새 임무를 등록하거나 사건을 조회·실행하지 않습니다.

이 대화의 기록

완료된 업무의 입력과 응답도 이어서 봅니다. 기록 자체가 검증된 근거라는 의미는 아닙니다.

개인 기억 이 담당과 사용자의 장기 기억

대화는 자동으로 개인 기억에 복사되지 않습니다. 기억할 발언을 선택하거나 새 발언을 입력하세요. 검색 결과도 ‘이번 업무에 사용’을 눌러야 문맥에 연결됩니다. 다시 선택하면 이전 선택을 대체합니다.

업무를 선택하면 이번 업무에 연결된 기억을 확인합니다.

이력에서 고른 발언은 그대로 저장합니다. 새 발언은 먼저 현재 업무의 대화에 저장합니다.

문서 초안 관리

카드에서 초안을 만든 뒤 표시된 파일을 사용자 편집기로 수정하세요. 저장한 파일은 ‘현재 업무에 명시 적용’을 눌러야 사용자 입력과 기억 정정으로 반영됩니다. 정본 파일은 직접 편집하지 않습니다.

결과가 끊기면 같은 적용 ID로 확인·재개합니다. 재개는 최초에 접수한 내용과 업무를 사용하며 새 파일 편집을 다시 가져오지 않습니다.

‘잊기’는 현재 개인 기억에서 제외합니다. 과거 대화 원문과 이미 저장된 기록·백업까지 삭제하는 기능은 아닙니다.

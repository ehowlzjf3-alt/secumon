# 구현 현황 HTML 안내서

주 산출물: [secumon-review.html](/Users/seunghanee/Documents/secumon/design/secumon-review.html)

HTML 한 파일에 내용·스타일·스크립트가 포함돼 있어 인터넷이나 서버 없이 열 수 있다. 다른 파일의 링크는 더 읽을 때 사용하는 선택적인 로컬 근거 링크다. 이 파일을 다른 위치에 복사해도 본문·검색·설명·단계 예시는 남지만 로컬 근거 링크의 위치는 달라질 수 있다.

- 8개 화면: 한눈에 보기, 전체 구조, 한 업무의 흐름, 기능별 구현, 동작·개발 방법론, 계획과 남은 일, 이번에 검토할 변경, 용어 사전.
- 16개 기능의 개념·동작·구현·한계·예시·코드/결과 문서.
- 31개 계획 항목의 상태·현재 결과·남은 범위와 검색/단계/상태 필터.
- 80개 용어·변수 설명과 본문의 용어 도움말.
- 정상/반증/중단 후 재개 3개 설명 사례, 문맥 정리와 자원 정산 예시.
- 인쇄/PDF용 스타일. 실제 모델·도구·네트워크 호출이나 자료 변경은 없다.

내용은 `status-snapshot.json`의 현재 코드/실행 기록과 명시적인 설명 자료를 결합했다. 기존 전체 작업 목록을 완료로 승격하거나 제품 코드를 수정하지 않는다. P4 단계 및 funding의 이전 상태 필드는 최신 개별 실행 기록과 구분해 설명한다.

## 생성과 검증

프로젝트의 Node 24.20.0으로 다음 명령을 사용한다.

```sh
node design/review/build.mjs
node design/review/verify-review.mjs
```

`status-snapshot.mjs`는 읽기 전용 상태 수집기다. 지금 확인한 검증 소스 digest와 다르면 중단하므로, 후속 코드에서 오래된 전체 시험 결과를 새 소스 결과로 재표시하지 않는다. 새 검증 기준선으로 업데이트할 때 근거를 다시 확인해야 한다.

`html-static-verification.json`에 HTML/스크립트 구조, 항목·용어·참조 연결, 외부 자원/네트워크 호출 부재와 제품 소스 불변 확인을 저장했다. 정적 검사는 통과했다. 실제 브라우저의 file URL 열기는 보안 정책으로 거절돼 자동 화면/조작 검수는 수행하지 못했으며, 다른 브라우저나 주소로 우회하지 않았다. 정적 검사 성공을 렌더링 검수 성공으로 표시하지 않는다.

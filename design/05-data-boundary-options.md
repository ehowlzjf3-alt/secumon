# 데이터 접근 경계의 대안

2026-09-05 · 범용 런타임의 정책 설계 · 시큐몬 중요파일 사례

범용 에이전트에서 리드/검토원은 고정 계층이 아니다. 아래는 정보 등급이 다른 두 역할이 협업할 때의 배치 대안이며, 사람 대화·연구·개발에도 동일한 목적지/권한 정책을 적용할 수 있다. 사용자 결정: 대안 비교 후 선택.

사람 대화 담당이라는 이유로 원문 권한을 자동 부여하지 않는다. 인증된 사용자의 열람 권한과 대화 모델 목적지의 전송 허용 범위를 각각 검사한다. 사람이 내부 원문을 볼 수 있어도 외부 대화 모델에 그대로 보낼 수 있다는 뜻은 아니다. TS·Python·Rust 중 어떤 언어를 선택하든 이 경계는 동일하다.


| 대안 | 정보 흐름 | 장점 | 비용·한계 |
|---|---|---|---|
| A. 외부 리드 + 내부 검토원 + 전송 전 공개 게이트 | 외부에는 허용된 주장·관계·가명 ID만 | 모델 선택 폭, 기존 역할 분리 활용 | 공개 정책·우회 없는 egress·누적 정보 노출 관리 필요 |
| B. 전체 추론을 내부에 배치 | 리드도 정책에 따라 내부 원문 접근 가능 | 외부 기밀 전송 경계가 단순 | 내부 모델 품질·자원·지연 검증 필요, 내부 권한 통제는 여전히 필요 |
| C. 내부 사건 관리자 + 외부 자문만 제한 호출 | 계획 평가에 필요한 추상 정보만 외부에 제공 | 내부가 판단과 실행을 통제 | 추상화로 잃는 정보, 자문을 매번 부르면 비용·지연 증가 |

**잠정 권고:** A와 B를 같은 사건·도구 계약 위에서 비교 가능하게 만든다. 내부 원문 분석과 데이터 게이트는 먼저 설계하고, 리드 모델 위치는 평가로 선택한다. 외부 추론이 꼭 필요한지 확인되기 전에 외부 리드 자체를 필수 요소로 고정하지 않는다.

사용자는 원문 접근 정책을 대안 비교 후 결정하기로 했다. A/B/C 중 어느 방식도 채택된 상태가 아니다. 원문 없이도 판단이 가능한지와 공개 가능한 정보 범위를 함께 평가한다.

### A에서 필요한 실제 권한 경계

- 원문 분석 워커: 필요한 사내 자료에만 접근, 외부 모델 endpoint 접근 차단, 최소 권한 자격증명.
- 원문 저장소: 별도 서비스 계정·마운트·DB role. 리드 서비스 계정에는 자격증명과 볼륨을 주지 않는다.
- 공개 게이트: 내부 결과를 정책이 허용하는 스키마로 투영한다. 자유 텍스트·경로·이미지는 기본 비공개이며 별도 허용 규칙이 있어야 한다.
- 리드 런타임: 공개용 view와 작업 제안 API만 접근한다. 원문 검색·범용 shell·DB 직접 조회·임의 tool relay는 노출하지 않는다.
- 모델 egress proxy: 최종 직렬화 요청의 시스템 메시지, 도구 스키마, 결과, 에러, 재시도와 폴백까지 목적지·등급 정책을 확인한다. 공개 게이트를 통과하지 않은 우회 네트워크를 막는다.
- 관측·로그·요약기·검색 색인도 같은 경계를 적용한다. 원문 요청 캡처는 내부 제한 저장소에서 짧은 보존기간으로 관리한다.

모든 요약을 의미적으로 완벽히 비밀 제거할 수 있다고 가정하지 않는다. 애매한 경우 내부에만 남긴다. 사후 감사는 전송 전 차단의 회귀 검증과 사고 추적에 활용한다.

### 원문 없이 판단할 재료

외부 리드용 결과는 정책이 허용하는 수준에서 다음을 제공한다.

- 가명 자산 ID·문서 ID·증거 ID, 사건 내부에서만 일관된 상관관계 ID.
- “인가된 권한 스냅샷에서 허용 대상이 정책 범위를 초과함” 같은 관찰 사실.
- 지지/반증 증거 참조, 관측시각, 자료 버전, 검토 범위, 미관측 범위.
- 확실한 판단과 검토원 추정의 구분, 다음에 내부에서 확인할 질문.

예를 들어 문서 제목·본문 없이 “동일 자료군의 두 문서가 서로 다른 접근 범위를 가진다”는 관계를 전달할 수 있다. 이것도 사내 정책상 공개 가능한지 확인한다. 상관관계 식별자는 내부 비밀키 기반 HMAC/가명 매핑처럼 관리하고 범위를 사건·조직 정책에 맞춰 제한한다. 짧은 hash나 길이/entropy를 준다고 정보 노출이 0이라고 주장하지 않는다. 여러 번의 질문으로 공개 정보가 누적되는 것도 관리한다.

원문 없이는 해결할 수 없는 의미 판단은 내부 검토원·내부 리드·사람이 맡는다. 외부 리드에 마스킹된 데이터만 주고 동일한 판별력을 보장할 수는 없다.


## 검증 방법

합성 자료로 동일한 과제를 A/B/C 배치에서 비교한다. 판단 정확도, 반증 발견률, 내부 재질의 횟수, 지연, 토큰 비용, 허용되지 않은 정보의 전송 여부를 함께 측정한다. 정규식 마스킹 통과만으로 보안 보장을 선언하지 않는다. 자유서술·경로·이미지·에러·로그·요약·검색 색인·폴백·여러 차례의 합성 결과를 점검한다. 원문 접근 정책은 이 결과와 사내 분류 기준을 보고 확정한다.

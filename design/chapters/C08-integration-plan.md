# C08 협업·반론·자원 구현

지속 담당의 수명과 개별 업무의 자원을 구분한다. 같은 범용 엔진으로 동료에게 묻거나 별도 문맥의 임시 검토를 실행하며, 게시판이나 부모/자식 자원 배정을 모든 질문에 강제하지 않는다.

- 직접 동료: 등록된 담당·모델·역할에 질문하고 해당 담당의 세션/저장 경계에서 실행한다. 출력은 검토 의견이며 독립 관측 근거로 자동 승격하지 않는다.
- 반론: 대상 버전, 대안, 근거 참조 또는 근거 없음, 판별 질문, 영향과 모델 식별을 구조화한다. 기존 다음 계획/가설 평가에 결과를 입력한다.
- 자원: 기존 BudgetDelegationService와 runtime.budgets를 모델 도구에 연결한다. 상태 조회, 명시 임시 업무 배정/실행, 추가 요청/배정, 회수, 정산은 작업 단위이다. 상주 담당과 세션은 종료하지 않는다.
- 구현 중 빌드/타입만 확인한다. 취소/재전달/usage 경합, 독립 모델의 의미 판단, 플랫폼과 운영 검증은 C06-C10-verification-plan.md에 모은다.

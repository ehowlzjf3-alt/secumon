# P2-06 정보 경계: 구현 계획

2026-09-06 · 학습 방식의 다음 구현 단위 · 실제 배치 선택은 미결정

이전 턴은 P2-05 평가 구현·검증 및 문서 정리를 완료한 진전이다. 이번 단위는 [전체 계획](/Users/seunghanee/Documents/secumon/design/03-migration-plan.md)의 P2-06을 이어간다. 실제 모델/API 시험 중단은 유지한다.

## 개념과 목표

자료를 읽을 수 있는 권한과 그 자료를 특정 모델·도구·사람·로그로 내보낼 수 있는 권한을 분리한다. 현재 Policy의 allowedLabels와 allowedDestinations는 독립 목록이다. 기존 자료 접근·원본 검증·저장/재개는 재사용하고 목적지별 공개 계약을 추가한다. 모델/도구의 자유서술 응답은 권한이나 새 사용자 명령이 되지 않는다.

## 구현 순서

1. Policy에 선택적이고 명시적인 목적지별 공개 정책을 추가한다. 활성 정책에서는 선언되지 않은 목적지/표면을 거부한다. 원문 등급이 없는 목표·가설·task input·지침·에러가 있으므로 전체 작업의 읽기 허용 등급을 해당 작업 출력의 보수적인 상한으로 사용한다. 내부 작업을 외부로 보내려면 별도 공개 뷰가 필요하다. 정책 없는 기존 합성 프로필을 강화된 정보 경계 검증으로 간주하지 않는다.
2. 모델의 estimateInput 이전과 propose 직전, 실제 도구 진입, 채널 send/lookup에 적용한다. 저장된 입력/compact/재시도도 현재 정책 검사를 통과해야 한다. 내부 모델 adapter의 최종 요청 snapshot에도 같은 검사를 적용한다. 부모보다 넓은 자식 공개 정책은 거부한다.
3. 신뢰된 배치 설정이 지정한 필드와 유한한 값 매핑만 공개하는 DisclosureService를 만든다. 원본 ID·경로·자유서술·이미지·에러는 투영하지 않는다. 원본과 현재 권한을 확인하고, 내부 근거/정책/규칙 digest와 공개 payload를 영속 기록한다. 같은 요청 ID의 반복과 누적 공개 한도, 재시작·원본 철회·정책 변경을 검증한다. 원본은 원래 등급에 남고 공개는 명시적인 별도 파생물이다.
4. 동일 합성 근거에 A(외부 리드+내부 게이트), B(전체 내부), C(내부 관리자+제한 자문)를 적용한다. 실제 경계 코드에 들어간 모델/도구/채널 payload를 수집해 금지 표식의 포함 여부와 공개 정보 손실·호출/byte 수를 비교한다. 두 상태 저장소를 사용한다. 실제 LLM 품질·반증 발견 능력·비용 우열은 이 시험으로 판단하지 않는다.

## 완료 근거와 한계

- 정상 허용과 같은 사용자의 외부 목적지 거부를 구분한다. 목표/가설/지침/도구 스키마/검색 카드/요약/로그/화면/artifact/채널과 반복 호출을 포함한다.
- 정책 철회가 추정/예약/dispatch/lookup 사이에 발생할 때 다음 실제 진입이 멈추는지 확인한다. 이미 전달된 정보가 소급 삭제된다고 주장하지 않는다.
- 실제 workflow의 제안 검증으로 tool/A2A 본문이 정책·목표 변경으로 승격되지 않는지 확인한다.
- 관련 시험 뒤 전체 npm run verify, 원본·lock·이전 검증 기록 보존, 소스/실행 근거를 저장한다. 계획·결과·학습·한계와 작업 상태를 갱신한다.

애플리케이션 계약은 임의 플러그인의 직접 네트워크/디스크 접근까지 격리하지 않는다. 실제 배치에서는 별도 신원·원문 볼륨/자격증명 격리·egress proxy·로그/백업 정책 검증이 필요하다. A/B/C 채택과 조직 자료 분류/보존 정책, 실제 모델 조건은 계속 미결정이다.

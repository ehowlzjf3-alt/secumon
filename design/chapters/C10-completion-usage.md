# C10 설치·복원 사용 시 달라진 점

설치·버전 선택·복원 명령은 기존 진입점을 사용한다. [설치·버전 안내](installation-and-versioning.md), [엔진 준비](C10-engine-preparation-usage.md), [복원 적용](C10-restore-recovery-apply-usage.md)와 [복원 후 대사](C10-restore-reconciliation-usage.md)를 따른다.

설치 묶음에는 실행 OS와 CPU에 맞게 빌드한 `native/windows-files/secumon_windows_files.node`가 필요하다. 디렉터리 이름의 windows는 기존 모듈 이름이며 Linux/macOS의 디렉터리 이동도 제공한다. 다른 플랫폼에서 복사한 바이너리는 사용할 수 없다. 일반 목록 조회는 이를 실행하지 않고, 명시 설치·등록 시 검증된 파일을 별도 프로세스로 로딩한다. 실제 NAS 검증은 개발용 Linux 바이너리였으며 release 최적화·네이티브 Windows 실행을 증명하지 않는다.

복원 도중 끊기면 같은 선택된 백업과 digest로 기존 복원 적용을 다시 요청한다. 이미 기록된 표식과 파일 신원을 확인해 이어가며, 확인할 수 없는 기존 경로는 보존하고 거절한다. 게시 전 남은 무작위 임시 디렉터리를 임의로 복원본으로 지정하거나 지우지 않는다. 복원 적용이 끝나도 외부 실행/저장소 대사가 끝나기 전에는 일반 작업 실행이 열리지 않는다.

대화·기억·원문과 과거 영수증은 기존 백업 정책으로 보존한다. 현재 작업에서 참조가 줄어든 것은 원자료 삭제를 의미하지 않는다. 단기 문맥, 개인 장기기억, 대화 이력, 선택 게시판/아카이브의 역할도 그대로다. 이번 시험은 작은 로컬 저장소의 복원과 재전달을 확인한 것이므로 실제 보관 기간·누적 자료 크기에 맞춘 백업/복원 시간은 배치 시 확인한다.

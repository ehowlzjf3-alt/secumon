# 웹의 미확정 상시 임무 요청

1. 웹 작업실의 **상시 임무**를 열고 등록할 때 받은 제어 업무 ID로 **상태 조회**를 누른다.
2. 필요한 관측 일시정지·재개·종료를 선택한다. 이 제어는 새 사건의 관측에 적용된다.
3. 응답이 끊겼다면 **같은 요청 다시 확인**을 누른다. 같은 탭에서 새로고침해도 해당 담당·대화의 미확정 요청을 복원한다. 여러 요청은 **확인이 필요한 요청** 목록에서 선택한다.
4. 원 처리 결과를 확인한 후 다음 제어를 선택한다. 현재 상태 조회만으로는 원 요청의 처리 여부가 확정되지 않는다.

새로고침이 명령을 자동 실행하지 않는다. 작업실은 요청의 식별정보만 탭 저장소에 보관하고 상태·대화 원문을 함께 저장하지 않는다. 인증이 만료되면 화면을 비우고, 동일 담당·사용자 세션·대화로 다시 연결했을 때만 복원한다.

저장할 수 없다는 안내가 나오면 탭을 유지하고 브라우저 저장 설정·공간을 확인한다. 미확정 요청은 오래됐다는 이유로 자동 삭제하지 않으며, 최대16건을 먼저 확인해야 새 요청을 저장할 수 있다. 탭 종료나 브라우저 데이터 삭제 이후까지 복원을 보장하지 않는다.

기존 [CLI와 Web 제어 사용법](C09-resident-command-usage.md)의 명령 의미와 권한 조건은 유지한다. 일반 업무의 취소·일시정지는 해당 업무 화면에서 다룬다.

# 전체 수집 조건과 저장 응답 복원

2026-09-06 · v0.42 · 로컬 구현·검증 완료

일부 자료를 읽은 상태와 요청한 전체 자료를 읽은 상태를 구분했다. 또한 도구 응답을 저장한 직후 프로세스가 종료되더라도, 저장된 응답을 다시 요청하지 않고 수집 진행 상태에 반영할 수 있게 했다.

## 개념과 구현

전체 수집이 필요한 완료 조건에는 조회 식별값과 선택적인 snapshot 조건을 지정한다. 호스트가 승인한 유한 항목 목록을 checkpoint에 고정하고, 실제 수집 항목과 대조한다. 원격 서버의 total이나 EOF만으로 업무 전체를 읽었다고 판단하지 않는다. 개별 Evidence와 독립 출처 수는 유지하며, 전체 수집 조건은 기존 사실·출처 조건에 추가로 적용한다. 모든 항목을 수집했다는 사실이 각 항목의 내용까지 특정 명제를 만족한다는 뜻은 아니다. 빈 목록도 부재 주장의 근거를 자동 생성하지 않는다.

복원은 원래 attempt의 마지막 요청과 저장 응답을 연결한다. 원본·권한·목표·등록 계약을 검증한 뒤 동일 수집 장부를 갱신한다. 원 응답 시각·재개 가능 시각·조회 snapshot·누적 호출 한도를 유지하며, 종료된 attempt를 성공으로 바꾸거나 그 결과를 자동 채택하지 않는다. 이후 명시적인 readResume가 현재 권한으로 남은 작업을 처리한다.

MCP 응답 해석과 receipt 조회는 외부 어댑터에 두었다. 코어는 응답 복원과 manifest 포트만 사용하며 특정 프로토콜·DB에 의존하지 않는다. 완료 조건과 공개·답변 준비·발송 경계는 현재 checkpoint와 원 응답을 검증한다. 원 응답이 사라지거나 요약이 변조되면 준비된 결과도 성공으로 표시하거나 발송하지 않는다.

## 관찰한 결과

관련 시험 154/154가 통과했다. 새 시험은 전체 수집 조건 10개, 두 업무군·두 저장소의 수집/공개 경계 7개, 저장 응답 복구 11개로 총 28개다. 기존 수집·대기·원본 검증 회귀도 포함한다.

복구 시험 11개는 실제 소유 worker를 SIGKILL한다. 이 가운데 SQLite/file journal × 전체 응답·비최종 페이지·제한 응답의 6개 기본 조합을 별도 측정 파일로 저장한다. 복원 자체의 모델·원격 호출은 0회다. 전체 응답은 새 원격 호출 없이 이어받고, 비최종 페이지와 제한 응답은 이후 필요한 한 번의 호출만 수행한다. 제한 응답은 원래 재개 시각을 유지한다. 중복 복원, 두 복원자의 경합, 상태 저장 직후 ACK 유실도 확인했다.

초기 관련 실행은 71/72였다. 원 응답 누락은 예상한 복원 단계보다 앞선 저장소 무결성 검사에서 거절되어, 실제 차단 지점과 미채택 상태를 확인하도록 시험 기대값을 수정했다. 이 수정으로 제품 동작을 완화하지 않았다. 별도 초기 타입·fixture 설정 오류도 수정한 뒤 최종 관련 시험을 수행했다.

전체 `npm run verify`는 **2,117/2,117**, 실패·취소·건너뜀 0으로 종료했다. 빌드·코어 타입 검사, 계층 검사 103파일/위반 0, fixture 4개/22판정도 통과했다. 전체 시험 시간은 299,241.139625ms이며 관련 154개는 이 전체 분모에 다시 더하지 않는다. 별도 lint 명령은 없다. [현재 실행·소스/빌드 검증 기록](/Users/seunghanee/Documents/secumon/runtime/evidence/P3-mcp-settlement-local-verification.json)에 결과를 저장했다. 현재 소스와 실행한 빌드의 일치를 확인했고 과거 코드·압축 파일·전체 이전 기록은 대조하지 않았다.

## 범위와 다음 챕터

승인된 유한 목록의 읽기 계약을 로컬 stdio MCP로 검증한 결과다. 임의 검색 공간의 완전 열거, 사내 MCP 명세·HTTP/OAuth·쓰기 효과, 실제 모델과 운영 환경의 검증은 남아 있다. 모델/API 시험 취소 상태를 유지한다. 복원 시 로컬 원본 검증 비용과 후속 실행의 논리적 도구 예산은 발생하므로 원격 재호출 0회를 비용 0으로 해석하지 않는다.

다음 로컬 챕터는 P4-01의 두 에이전트와 게시판이다. 역할 ID·개인 관측·공유 대상·근거 인용을 연결하고, 동일 출처의 중복 인용·충돌·철회·권한·대화 상한을 검증한다. 실제 연동에 필요한 외부 조건은 해당 경로에 남기며, 전체 P0–P6 완료로 처리하지 않는다. 원래 시큐몬과의 동작 일치를 새 설계의 완료 기준으로 삼지 않는다.

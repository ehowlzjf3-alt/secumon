## 이번에 마친 범위

- 게시판: 다른 담당의 업무는 명시 등록한 원출처 검사기로 읽으며, 같은 DB에 행이 있다는 이유로 출처를 대신하지 않는다. 반복 해제와 조회 중 해제가 후속 등록·늦은 응답을 잘못 채택하지 않는다.
- 독립 담당: 다른 디렉터리·SQLite DB의 일반 profile 입력으로 선택 답글과 명시 요청 수락·답변·요청자 확인을 구분했다. 게시판 자료를 개인 기억이나 독립 Evidence로 자동 복사하지 않는다.
- 아카이브: 검색 카드→명시 원문, 등록/정정/삭제와 응답 유실 뒤 원 receipt 복구를 확인했다. null/변조 receipt를 완료나 재실행 허가로 바꾸지 않는다.
- 도구 효율: 새로운 참고자료와 실제 적용한 게시를 진전에 연결하고, 동일 내용의 ID·시각·revision 변화만으로 반복을 이어가지 않는다. 게시 결과의 검증된 committed revision으로 불필요한 즉시 재조회를 줄였다. 다음 명령의 현재 권한·CAS 검사는 유지한다.

메인 프롬프트는 공통 범용 지침으로 구현·연결돼 있다. [현재 설명](chapters/prompt-generality-review.md)은 실제 모델 품질 검증과 구분한다. C01~C06 이전 결과는 각 실행 소스의 기록이며 이번에 반복 실행하지 않았다.

실제 PostgreSQL·사내 MCP/Knox·A2A 상호운용·registry 게시·버전 간 업그레이드·운영 설치는 미실행 범위를 유지한다. 활성 빌드·시험은 없다. 세션은 이어가되 목표·근거·실행 영수증·자원 장부는 작업별로, 신원·설정·기억·대화는 담당별로 분리한다.
